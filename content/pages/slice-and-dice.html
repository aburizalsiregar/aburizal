A short dice-based roguelike game loosely set in Victorian London.

Company: Self-project
Project Type: Game Jam
Platform: Windows
Genre: Typing game
Status: Released

Play: itch.io

Primary Role: Programmer (Unity)

Entry for BGDJam 2022, and won 1st place. A roguelike game a la Slay the Spire but with dice-based battle. You assign dice to your skills. Some skills have requirements, like odd/even numbers or number 4 or more. The theme is set in Victorian London with a black-and-white aesthetic to cut on asset development time, but it ends up becoming the game’s charm.

I am responsible for:

  • Programming
  • Testing and balancing
