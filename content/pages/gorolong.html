Primary Role: Game Designer, Game Director

This is a game project for Fun Ken Pon, Karya Eka Nala’s game division. A simple but challenging mobile game that utilizes the phone’s accelerometer sensor. The screen will perpetually be moving up, so the player must roll the Cat down the platforms in order to keep playing. The area will change the more you roll down, from apartments to sewers to caves.

I am responsible for:

  • Pitching the concept
  • Core gameplay loop
  • Overall art style and narrative design
  • Various balancing on system mechanics, such as the game and character’s movement speed, shop system, and scoring system.
  • Overseeing the development team
