Comfy and cutesy first-person turn-based dungeon crawler. Play as a party of animal adventurers to search for the legendary recipe!

Company: Self-project
Project Type: Game Jam
Platform: Windows
Genre: Dungeon Crawler RPG
Status: Released

Play: itch.io

Primary Role: Project Lead, Programmer (RPG Maker)

This entry is inspired by Etrian Odyssey, and also to test my programming skills. I set out to create a comfy, relaxed atmosphere. I incorporated many sokoban-style puzzle elements, multiple levels of elevation, and unmappable areas. I am pretty satisfied with the result, but there still can be aspects to be improved upon like combat balance and writing.

  • Programming
